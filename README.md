On the left deck make sure to start with the lp filter knob fully cw.
Start with the mix knob on about 10 o clock 
In the right deck make sure to start with the pitch knob in the middle and mix knob and time knob fully cw.
The pitch knob next to the middle one (the pitch shifting one on the right not the middle) should be at 12 o clock
The random knob should be at minimum at first
Also make sure to check and move all knobs since some of them are preset to some default values when the spotykach is turned on.
You can always have a look at the image I have uploaded to navigate visually more easily.
